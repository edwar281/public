AI analyst · Ookla speed tests, 2019–2026

Ask the broadband data

An AI analyst that answers questions about US internet speeds. It writes SQL and Python, runs them, reads the results and explains what it found. You see every step.

It works from 594 million speed tests summarized by county and quarter. Pick a question to start.

How it works

  1. Gemini plans the analysis. A small Cloudflare Worker keeps the API key off this page and passes the conversation to Gemini along with two tools, one for SQL and one for Python.
  2. The code runs here, in your browser. Python and DuckDB, compiled to WebAssembly, load the data into a background worker that is separate from this page, and any step that runs longer than 30 seconds is stopped.
  3. The results go back to the model, which reads them, corrects its own errors and writes the answer. Token counts and timings for the model and the code appear under each answer.

The example questions replay a saved live run, so they load instantly. Your own questions run live on Gemini's free tier, which has a daily limit.
