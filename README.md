## Projects in this repo

- **[Broadband Analyst](ai-analyst/)**: an AI agent that answers plain-English questions about US internet speeds by writing and running SQL and Python in the visitor's browser, with every step shown. [Try it](https://edwar281.github.io/public/ai-analyst/).
- **[Subscription churn at scale](kkbox-churn/)**: survival analysis and an out-of-time LightGBM churn model on 392M usage records (AUC 0.869, 6.0x top-decile lift). [Open the analysis](https://edwar281.github.io/public/kkbox-churn/dashboard/).
- **[Did the rate cover the risk?](lending-club-credit/)**: realized returns on 2.26M Lending Club loans and what an application-time risk model would have added. [Open the analysis](https://edwar281.github.io/public/lending-club-credit/dashboard/).
- **[Closing the broadband gap](ookla-broadband/)**: seven years of Ookla speed tests mapped to every US county, the rural gap, and outage detection. [Open the analysis](https://edwar281.github.io/public/ookla-broadband/dashboard/).
